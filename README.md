# RL

A single-player, first-person extraction shooter made with Godot 4.7.
Post-apocalyptic, realistic and tense, with esoteric and alchemical themes that
grow deeper level by level.

> WW2 started the race for the bomb. During the Cold War a classified US
> program started another race: back into alchemy and its otherworldly powers.
> It worked. Humanity became too powerful, and the world fell apart. What is
> left belongs to deities, monsters and entities, and to the last people
> picking through the ruins.

## Current build

- **Level 1, The Works**: an abandoned industrial complex about 200 m across,
  generated fresh every run (and every retry) and built while the level
  loads. It grows like a real site: buildings of irregular shape (wings,
  notches, setbacks, the odd corner cut at 45 degrees) added one against
  another or linked by covered walkways with ribbon windows, bridges between
  upper floors, a walled courtyard or two, open ground, and beyond the fence
  embankments and rolling scrubland hills under a hazy skyline. Overcast daylight falls in through tall arched hall
  windows, office windows and roof holes. Three districts blend into each
  other: the factory floor (halls with
  conveyor lines, presses, lathes, generators, assembly robots, catwalks and
  bridges under a travelling crane; foundries with furnaces, moulds and slag;
  processing plants with reactors and vats), the interior (cramped service
  corridors and office blocks: cubicles, private offices, meeting rooms,
  archives, boiler rooms, electrical rooms, locker rooms, washrooms,
  workshops) and storage (pallet-rack warehouses, parts stores, wire cages,
  loading docks). Nothing is intact: fallen ceiling tiles, toppled lockers,
  doors off their hinges, collapsed racks, broken glass, leaks, rust and damp,
  moss under the roof holes. Two or three exits are scattered far from the
  start; some are hidden maintenance hatches, some need a breaker pulled
  first. Holes broken through walls and crawl vents (some half hidden behind
  a dragged locker) make shortcuts and odd connections, and a couple of
  hideouts can only be reached by crawling. Floors rise and fall: machine
  plinths and platforms with steps, sunken pits.
- **Dark where nothing lights it**, with a flashlight on T. A few things are not quite right. The seed is shown in the pause menu.
- **You start with an M1911 and one spare magazine.** The AK-47, M16A2, MP5,
  M40, Makarov PM, TT-33, PPSh-41 and SKS and their ammunition lie around the
  level (placeholder pickups until the loot system is designed).
- **Firearms**: M1911, AK-47, M16A2, MP5, M40, Makarov PM, TT-33, PPSh-41 and
  SKS with real ballistics (velocity and drop), fire modes
  (semi/burst/auto/bolt), chambering, tactical and empty reloads,
  round-by-round loading for the M40 and SKS, recoil, ADS, a 10x scope.
- **Rival scavengers** (animated, gas-masked) who patrol, hear gunshots and
  footsteps, investigate, spot you, fight in bursts and reload from cover.
- **Audio** for every shot, reload, impact, footstep, casing and the
  ambience, plus menus, HUD, settings (graphics presets, sensitivity, FOV,
  volumes).

Most models, textures and sounds are generated by scripts in `dev/` and can
be swapped for real assets without code changes. Third-party assets (the
Soviet guns, the animated mannequin, some sounds, god rays) are listed in
`CREDITS.md`.

## Setup (Windows, everything on E:)

All local installs for this project go on the **E: drive** (see `CLAUDE.md`).

1. Clone the repo to `E:\Projects\RL`:
   ```
   git clone https://github.com/tddk777/RL.git E:\Projects\RL
   ```
2. Install Godot to `E:\Tools\Godot` (downloads and verifies the official
   build, and turns on self-contained mode so editor data stays on E:):
   ```
   powershell -ExecutionPolicy Bypass -File E:\Projects\RL\tools\setup-windows.ps1
   ```
3. Open the project:
   ```
   E:\Projects\RL\tools\open-editor.cmd
   ```
   Press **F5** to play. The first open imports all assets, which takes a
   minute.

## Controls

| Action | Key |
|---|---|
| Move | W A S D |
| Sprint / crouch / jump | Shift / Ctrl or C / Space |
| Fire / aim | Left / right mouse |
| Reload / fire mode | R / B |
| Weapons | 1-5, in the order you picked them up |
| Interact | F |
| Pause | Esc |
